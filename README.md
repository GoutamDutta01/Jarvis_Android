# Jarvis Android

Android evolution of the Jarvis desktop voice assistant.

## Goal
Turn Jarvis into a system-style Android voice assistant with voice activation, structured commands, Android-native actions, accessibility-based UI interaction where appropriate, and notification ingestion.

## Source
The original desktop implementation is in `GoutamDutta01/Jarvis_AI_Voice_Assistant`.

## Development milestones
1. System assistant foundation
2. Speech pipeline + structured command protocol
3. Calls, apps, camera, media, maps, search and alarms
4. Notification ingestion and supported replies
5. Cross-app UI workflows
6. Wake-word and autonomous multi-step agent

The Android implementation intentionally replaces Windows-specific automation and browser speech recognition with Android-native services.
